YouTube Homepage UI Clone
🔗 Project Overview

This project is a YouTube homepage UI clone built using HTML and CSS only.
The objective was to replicate the layout and structure of YouTube’s homepage to strengthen frontend layout skills and understand complex UI structuring.

This project focuses purely on visual design and layout recreation.

🚀 Features

Responsive navigation bar

Sidebar navigation menu

Video grid layout using CSS Grid

Thumbnail cards with duration overlay

Structured video metadata (title, channel name, views, time)

Clean spacing and alignment

🛠️ Tech Stack

HTML5

CSS3

Flexbox

CSS Grid

📚 What I Learned

Building complex layouts from scratch

Proper usage of Flexbox vs CSS Grid

Positioning elements using relative and absolute positioning

Maintaining consistent spacing and alignment

Structuring scalable frontend layout sections
